# LUXCAST POP & INTERIORS — Production Static Website

Premium, image-led static website for GitHub Pages.

## SEO positioning

Primary search intent:
**POP & False Ceiling Contractor in Hyderabad**

The page title, meta description, H1, service copy, LocalBusiness schema and visible content are aligned around the same primary intent and supporting services:
- POP ceiling
- false ceiling
- wall punning & finish
- PVC/WPC wall panelling
- custom PVC cabinets
- grid ceiling
- office interiors
- Hyderabad
- ChandrayanGutta / Hafez Baba Nagar

The `keywords` meta tag is included for completeness, but modern search engines do not use it as a primary ranking signal.

## Image policy

The 20 supplied images have been converted to WebP and optimized for web delivery. They are used as a visual gallery/reference set. The website deliberately does not claim that every supplied image is a completed LUXCAST project. Named business/institutional experience is listed separately and only reflects information supplied by the business owner.

## Deploy

Upload the contents of this folder to the `main` branch of:
`https://github.com/LuxCast/Service`

Then enable:
GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`

Expected URL:
`https://luxcast.github.io/Service/`
